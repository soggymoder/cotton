# cotton

cotton is a small stack machine for the cot programming language (a concatenative language inspired by Lua, Forth and a bit of Uxntal) written in C99

cotton is a passion hobby project being made solely by me, so, dont expect anything grandiose or of high quality - even then, suggestions and ideas are always welcome!! :D

## building cotton

```
meson setup build
ninja -C build
```

## running cotton

```
cotton <file.cot>
```
